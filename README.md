# 🎮 Tic Tac Toe (Android - Java)

## 📌 Overview
This project is a simple Tic Tac Toe game developed using Java in Android Studio. It demonstrates core game logic, user interaction handling, and basic mobile application development.

---

## 🎯 Features
- Two-player gameplay (Player X vs Player O)  
- Winner detection (rows, columns, diagonals)  
- Draw condition handling  
- Interactive UI with real-time updates  
- Restart game functionality  

---

## 🧠 Concepts Used
- Game logic implementation  
- Event handling in Android  
- UI component interaction  
- State management  

---

## 🛠 Tech Stack
- Java  
- Android Studio  
- XML (UI design)  


---

## 🚀 How It Works
- Players take turns marking X and O on the grid  
- The system checks for a winner after each move  
- If all cells are filled without a winner, the game results in a draw  
- Users can restart the game anytime
